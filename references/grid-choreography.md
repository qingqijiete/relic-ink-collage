# 动线编排与九格衔接

九宫格失败通常不是单格画得差，而是**边口对不上**。本文件给出可直接照抄的边界参数。

## 三种基本结构

### 竖通（Vertical）

纸带沿纵轴流动，主要服务单列叙事。

```
顶边 [X]% 宽度进入 → 绕过主体后侧 → 底边 [X]% 宽度离开
```

同一列上下两格用同一个 X，拼合后纸带成为一条完整竖带。

### 横贯（Horizontal）

纸带横穿画面，适合单幅与三列并置。

```
左边 [Y]% 高度进入 → 横贯 / 回旋 → 右边 [Y]% 高度离开
```

左右相邻两格必须共用同一个 Y。

### 斜卷（Diagonal Scroll）

纸带从左上角盘旋到右下角并逐渐收细，适合九格通铺。这是九宫格的首选结构，因为它天然产生跨格连续性。

```
第1格左上进入 → 依次穿过 2、3、5、6、8 → 第9格右下收束
```

## 九格参数表（斜卷）

参数写成 `边 + 百分比`，同一组数字在相邻两格必须互为镜像。

| 格号 | 位置 | 进入 | 离开 | 衔接对象 |
| --- | --- | --- | --- | --- |
| 1 | 左上 | 左上角（纸卷最宽处） | 右边 42% 高度 | → 2 |
| 2 | 上中 | 左边 42% 高度 | 右边 64% 高度 | 1 → 2 → 3 |
| 3 | 右上 | 左边 64% 高度 | 右边 28% 高度 | 2 → 3 |
| 4 | 左中 | 顶边 34% 宽度 | 底边 62% 宽度 | ↑1 ↓7 |
| 5 | 中央 | 左上角进入，绕主体大回旋 | 右下角离开 | 2 ↑ 4 ← 6 → |
| 6 | 右中 | 顶边 58% 宽度 | 底边 42% 宽度 | ↑3 ↓9 |
| 7 | 左下 | 顶边 42% 宽度 | 右边 58% 高度 | ↑4 → 8 |
| 8 | 下中 | 左边 58% 高度 | 右边 42% 高度 | 7 → 8 → 9 |
| 9 | 右下 | 左边 42% 高度 | 右下角收细收束 | ← 8 |

读法：第 2 格"右边 64% 离开"，第 3 格就必须"左边 64% 进入"；第 4 格"底边 62% 离开"，第 7 格就"顶边 62% 进入"。表里第 7 格写作 42% 是竖列另一条支线的参数，实际使用时坚持**一格只跑一条主线**，副线用银白枝影补足。

## 九格参数表（横贯＋竖通混合）

适合不想做斜卷、希望更"展厅式"整齐的情况。三列各自竖直，一条横带贯穿中行。

| 列 | 竖通参数 | 中行（4/5/6）额外横贯 |
| --- | --- | --- |
| 左列 1/4/7 | 顶边 62% ↔ 底边 62% | 4 的右边 48% 接 5 |
| 中列 2/5/8 | 顶边 58% ↔ 底边 58% | 5 的左 48% / 右 48% |
| 右列 3/6/9 | 顶边 35% ↔ 底边 35% | 6 的左边 48% 接 5 |

## 中央格优先

九宫格先画第 5 格。中央格确定四件事，其余八格照抄：

1. 米白纸的实际色温与明度。
2. 撕纸毛边的粗细尺度。
3. 银白线的亮度与宽度。
4. 器物的投影强度与光源方向。

中央格不稳定就批量生成，会得到九张各自为政的图。

## 衔接检查表

拼合后逐条核对，任一项不通就重生成对应格，不要用后期修图硬接：

- [ ] 纸带在相邻两格的边口高度一致（误差目测半格以内）。
- [ ] 纸带宽度在边口处连续，不出现突然变粗或变细。
- [ ] 纸带明度在边口处接近，不出现一格亮一格暗。
- [ ] 跨格枝影/银线的粗细与灰度一致。
- [ ] 相邻格的底色明度接近，没有明显"补丁感"。
- [ ] 拼合后视线能从左上走到右下，不需要跳着看。
- [ ] 每格单独看也成立，不是纯粹的画面碎片。

## 单幅的动线

单幅不需要跨格，但同样需要主动线，否则五件器物会散。

推荐：一条横贯纸带 + 一条竖向玉柱／建筑构件形成十字骨架，器物挂在骨架上；或者一条斜卷从左上到右下，器物沿卷面依次落位。

单幅的纸带通常比九宫格更宽（约为画布宽度的 18–26%），因为它要承担承托功能而不只是连接。
