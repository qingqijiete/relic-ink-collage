# 风格系统

本文件描述"墨影窗格"这套视觉的具体参数与失败模式。写提示词时据此填色与质感，不要凭感觉改主色。

## 色彩

| 角色 | 参考值 | 面积占比 | 说明 |
| --- | --- | --- | --- |
| 深墨黑 | `#0c0d0d` | 40–55% | 主底，负空间，必须占主导 |
| 极深苔绿 | `#101a15` ~ `#16241c` | 15–25% | 与墨黑交错，形成阴影层 |
| 灰绿切片 | `#3f4d44` ~ `#5b6a5e` | 8–15% | 窗格与摄影残片，低饱和 |
| 米白纸 | `#ded6c4` ~ `#efe8d8` | 12–22% | 撕纸、纸带，是唯一大面积亮色 |
| 银白线 | `#c9c7be` | <1% | 发丝线，低亮度，不刺眼 |
| 暗金线 | `#8a6f3c` | <1% | 少量点缀，不用亮金 |
| 器物本色 | 来源照片 | 按器物 | 青铜青绿锈、玉的墨绿褐斑、瓷的青花、彩绘的红绿 |

规则：

- 米白纸是唯一亮色，不要同时出现第二组高明度色块。
- 器物本色允许保留饱和度，但不得整体重染成统一色调。
- 出现第三种大面积彩色（如整片钴蓝）时，说明跑成了 `five-relic-color-collage` 的配色，需回头改提示词。

## 纵向层次

五层从后到前，提示词里按这个顺序描述最容易得到纵深：

1. **底**：墨黑 / 苔绿，接近纯色，允许极轻的纸纹与颗粒。
2. **窗格层**：错位竖向窗框、灰绿摄影切片，轻微失焦。
3. **撕纸层**：米白纸片构成地面、台阶或承托面，边缘毛糙，有真实投影。
4. **纸带层**：宽纸带穿行，翻卷处有厚度的明暗变化。
5. **器物层**：摄影质感的主体，锐利，边缘干净，落地有投影。
6. **线层**：银白与暗金细线压在最上，但不遮纹样。

## 器物处理

可以做：

- 去除展柜、展台、射灯、地砖、玻璃反光。
- 改变位置、尺度、倾斜角度、前后关系。
- 让器物被纸带部分遮挡（不遮纹样核心区）。
- 局部提亮或压暗以匹配光源方向。

不可以做：

- 改变器物轮廓比例、纹样结构、铭文内容。
- 把两件器物合成一件，或从一个器物"借"部件给另一个。
- 生成来源照片中不存在的部件（缺盖的补盖、断足补足）。
- 给器物添加文字、年号、馆藏号。

## 常见失败模式

| 现象 | 原因 | 修正 |
| --- | --- | --- |
| 九格拼合后纸带错位 | 相邻格边口参数不一致 | 成对写死"左格右侧 32% 离开 / 右格左侧 32% 进入" |
| 纸带断成几截 | 提示词没限定"连续" | 加"必须是一整条连续的带子，不要断成几段或碎成小块" |
| 画面变成九块独立小图 | 缺少跨格元素 | 指定每格的进入边、离开边与衔接元素 |
| 多了第四件器物 | 未限定数量 | 写"五件器物，每件只能出现一次"并列清单 |
| 出现伪汉字或印章 | 提示"书法""铭文" | 改为"无语义笔触"，并在负面清单里禁文字 |
| 器物变形、纹样糊 | `input_fidelity` 偏低或提示过长 | 提高保真度，精简动词，强调"保留轮廓、纹样、锈色与残损" |
| 整体偏灰、缺黑 | 窗格与切片面积过大 | 提高墨黑占比，压低切片明度 |
| 玉器被压扁 / 长条器变宽柱 | 尺度描述缺失 | 给出比例约束，如"高度约为宽度的六倍" |
| 撕纸太整齐像剪贴 | 未描述手工感 | 加"手工撕纸、毛边、旧纸纤维、纸屑" |
| 右下角角标清不掉 | 角标压在浅纸上 | 提示词要求右下角保持深色负空间 |

## 与其他视觉路线的边界

- 出现高纯度红黄蓝、顶部五格来源带 → 属于 `five-relic-color-collage`。
- 出现大面积纯黑无窗格、只有书法与水墨 → 属于单纯的书法拼贴，不是本系列。
- 出现真实场景（展厅、庭院照片）作为背景 → 破坏"纸上剧场"，应去掉。
