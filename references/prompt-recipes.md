# 提示词配方

三个模板对应三种输入形态。方括号内是必填占位，其余保持原样。

## 通用约束句（每个模板都要带）

```
严禁任何可读或伪造的文字、汉字、字母、数字、印章、logo和水印；不要顶部来源图带，不要标题，不要装饰边框。
```

## 模板 A：单幅（1–3 张来源图）

```
以三张输入照片为唯一文物来源，创作一张2:3竖版中国文化超现实拼贴。
三件器物，每件只能出现一次：
1. [器物A：形制 + 材质 + 纹样特征 + 颜色]，[在画面中的位置与角色]；
2. [器物B：……]，[位置与关系]；
3. [器物C：……]，[位置与关系]。
三件器物都必须清晰可辨、形制准确，严格保留来源轮廓、比例、材质、纹样、颜色和残损，不新增器物，不合并器物，不编造铭文。
去除展柜、展台、标签、射灯、地面和原摄影背景。

风格：深墨黑与极深苔绿为底，灰绿摄影切片、错位竖向窗格、大面积黑色负空间；米白手工撕纸、旧纸纤维、极少量银白与暗金细线。保留器物的真实颜色，不统一重染。

空间：一条米白长纸带从左边约[38]%高度进入，[穿行方式]，从右边约[66]%高度离开；纸带是一整条连续的带子，不断裂。器物之间有明确的前后遮挡、真实投影与尺度突变，不是并排陈列。

混合媒介：摄影、手工撕纸、水墨与细腻印刷颗粒结合，有真实纵深。
画面右下角保持大面积深色负空间。
```

## 模板 B：九宫格单格（第 N 格，3 件来源图）

在模板 A 的基础上，把空间段换成跨格段：

```
空间：米白长纸带从[左边约32%高度]进入，[穿行方式]，从[右边约32%高度]离开，衔接左右格；一条[银白枝影/灰绿竹枝影]从[底边约58%宽度]离开，衔接下方格。纸带是一整条连续的带子，不断裂。
```

九格完整参数见 `grid-choreography.md`，不要临时改数字。

## 模板 C：素材板（超过 3 件器物）

```
以输入素材板中的[五]件器物为唯一文物来源，创作一张2:3竖版中国文化超现实拼贴。
素材板只提供这[五]件器物的形状、比例、材质、纹样与锈色，请完全重新构图，绝对不要保留素材板的矩形排布、深色底板、展柜、展台、地面、射灯和任何摄影背景。
[随后接模板 A 的器物清单与风格、空间段]
```

关键句是"只提供……请完全重新构图"。缺这句时，模型大约有一半概率照抄素材板的行排布局。

## 器物描述写法

每种器物写四项，顺序固定：**形制 → 材质 → 特征细节 → 颜色**。

- 好：`三足双耳青铜大鼎（正立面，腹部兽面纹与扉棱，青绿锈）`
- 差：`一个古代的鼎`（信息量不足，模型会补出想象纹样）

长条器与特殊比例必须给数值约束：

- `四面出牙的细长方柱，高度约为宽度的六倍，不能压扁成宽方形或堆叠成塔`
- `细长竖直，从画面中部贯穿到顶部，宽度不超过画面宽度的十分之一`

## 角色指派句

给每件器物分配主角、支撑、呼应，避免"排队"：

```
[主角]位于画面上部，体量最大，是主视觉重心；
[支撑]作为中景弧形曲面，在主角左下方承托并环绕；
[呼应]沿纸带弧线悬浮在左下，头朝左上，与主角上下呼应。
```

不要写"三件器物从左到右依次排列"。

## 负面清单（可整段附加）

```
不要：第四件器物、展厅环境、射灯反光、玻璃、标签、展台底座、
整齐排列的三件式构图、蒙德里安式等分网格、密集蛛网细线、
可读文字或伪文字、印章状符号、卡通化渲染、塑料质感、过曝高光。
```

## 生成参数建议

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| `size` | `1024x1536`（单幅）/ `1024x1024`（九宫格单格） | 与最终拼合比例一致，避免二次裁剪 |
| `quality` | `high` | 撕纸毛边与细线需要足够分辨率 |
| `input_fidelity` | `high` | 器物还原优先于风格自由发挥 |
| `background` | `opaque` | 需要完整画布，不要透明底 |
| `revise` | `false` | 让提示词原样生效，避免被自动改写 |

## 迭代策略

1. 先跑中央格 / 单幅主体，作为风格基准。
2. 若器物变形但风格正确 → 保持风格段不动，加强器物段的形制与比例描述。
3. 若风格漂移但器物正确 → 保持器物段不动，重写风格段并补负面清单。
4. 单次只改一个段落。一次改全部会无法判断是哪个变量起作用。
